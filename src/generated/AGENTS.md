## Scope

Applies to `src/generated/`.

- Files in this directory are generated by GraphQL Code Generator.
- Never edit generated TypeScript manually.
- Make source changes in `api/graphql/schema/index.ts` and the relevant `src/*.graphql` documents, then run `yarn codegen` from the repository root.
- Review generated diffs for unexpected schema or operation changes.
- Commit generated output when its source schema or operations changed.
- Do not suppress lint or TypeScript errors by patching generated output; fix the schema, operation, codegen configuration, or consuming code instead.
